# YouBike Demand Prediction & Optimization

## Project Overview
This project aims to predict short-term YouBike station demand using historical usage data, weather information, and time-based features.

## Objectives
- Analyze YouBike usage patterns
- Build machine learning models for demand prediction
- Compare different forecasting approaches
- Explore bike redistribution optimization

## Planned Tech Stack
- Python
- Pandas
- NumPy
- scikit-learn
- XGBoost
- PyTorch
- Matplotlib
- OR-Tools / PuLP
